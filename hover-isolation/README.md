# 上浮动画交叉隔离测试

在仓库根目录运行 PowerShell：

```powershell
$env:QT_QPA_PLATFORM = 'windows'
& '.\.venv\Scripts\python.exe' '.\hover-isolation\runner.py'
```

统一控制窗提供 5.4.3 / 5.5.0 绘制结构与 QTimer / QVariantAnimation 的四种组合。
上浮高度为 0–300 逻辑像素，时长为 0–6000ms，0ms 立即到达终点。
默认 1px、140ms、OutCubic；QTimer 间隔 16ms。曲线选择下方显示公式。
滑块释放后应用参数，也可直接输入数值。切换参数会重建测试窗口并重置记录。
演示窗为 1500×850，使用 demo-annotations.json 中用户提供的完整文本和标注。
鼠标移入标注观察，或将鼠标留在控制窗并点击“重播 be 上浮”。

## 保存帧记录

保存当前版本从创建以来的 paintEvent 入口记录到 `<版本>+<计时方式>-frames.json`。
JSON 包含版本、高度、曲线、时长，以及每次绘制的相对时间 ms、上浮量 lift、
悬停目标 hovered、视图尺寸 size。切换设置和关闭控制窗也会自动保存；同名文件覆盖。
如需比较不同参数，请先另存生成的 JSON。生成记录不纳入 Git。

记录可用于比较绘制间隔是否有明显空档、上浮量是否跳变、目标或视图尺寸是否改变。
记录包含静止期和重播，不只有动画帧；分析时应截取同一次动画的时间段。
它记录应用绘制事件，不是显示器实际呈现时间，也没有分别记录文字和标注的像素位置，
因此不能独自证明画面流畅或两者同步，需要结合实际观察或录屏。

## 文件与隔离边界

- runner.py：统一入口、参数控件、计时替换和帧记录。
- demo-annotations.json：演示文本与标注数据。
- snapshots/：创建隔离实验时保存的旧版和新版源码及加载依赖。

快照不跟随主程序更新，5.5.0 快照也不等于现在已经回退动画的主程序。
没有 API 请求；未复现完整 Demo 的网络与后台工作负载。
QTimer 测试包装通过 QEasingCurve.valueForProgress 求值；默认 OutCubic 与旧公式
数学等价，但包装代码并非逐字相同。OutBack / OutElastic 可能超调，OutBounce 会回弹。
上浮距离很大时可能越过视图边界而被裁剪，这是保留原绘制结构时的行为。

离屏检查（验证逻辑，不验证屏幕流畅度）：

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
& '.\.venv\Scripts\python.exe' '-B' '.\hover-isolation\runner.py' '--smoke'
```

## 文字绘制方式

控制窗可独立选择原始 QTextLayout.draw 或字形轮廓方案，与四种窗口/计时组合搭配。
UI 会显示当前窗口结构、计时机制和文字绘制技术栈。
轮廓方案使用原 QTextLayout 的 glyphRuns 获取已塑形字形、位置与格式范围，
通过 QRawFont.pathForGlyph 缓存轮廓，再用 QPainter.fillPath 抗锯齿绘制。
静止与动画统一使用轮廓，以避免起止时切换渲染方式；原有背景、裁剪、颜色和加粗保留。
这会改变文字锐利度和绘制成本，是实验选项，不修改 snapshots 或主程序。
默认仍为原始文字绘制。记录文件名加入 native / outline，避免两种绘制模式互相覆盖。
控制窗的关闭悬浮窗按钮可关闭测试窗口，再次点击可重新打开。

控制窗按版本与绘制、动画参数、缓动公式分区；说明区可滚动，操作按钮固定在底部。

## 独立进入、退出与多标注动画

进入和退出分别提供 0–6000ms 时长滑块。退出默认“无（立即复位）”，
可选择与进入相同的十种缓动曲线；0ms 立即到达对应终点。
每个标注拥有自己的计时器和位移，切换目标后，旧目标可继续回落，新目标同时上浮。
QTimer 模式为各标注使用 16ms + monotonic；QVariantAnimation 模式使用独立 Qt 动画对象。

进入、退出时长均指走完整条曲线的时间。位移为 `高度 * f(p)`，进入 p 增至 1，
退出 p 减至 0；退出不再用原来的 `1-f(t)`，而是倒着走所选曲线。

方向改变时，同曲线保留最近一次绘制的进度 p，直接反向推进；异曲线求解
`新曲线(p)=当前位移/高度`，从求出的进度继续。剩余时长分别是
`进入时长*(1-p)` 和 `退出时长*p`。Qt 动画时长取整到毫秒，最短 1ms；QTimer
按 monotonic 的实际经过时间推进。0ms 和“无”仍立即到达终点。

非单调曲线可能有多个逆解：使用分段采样定位和二分求根，优先选择最接近旧进度的解。
不同曲线速度并不保证连续。若当前超调位置超出新曲线可达范围，数学上没有逆解：
选择最接近的曲线位置并保留残余位移，让残余在剩余段内线性衰减，避免突然跳变。
这时是明确的连续性补偿，并非严格沿新曲线移动。若最近点恰为目的端点却仍有残余，
改用完整段完成补偿。测试记录包含各动画 phases，便于核对反向计时。
其他标注的动画不受打断影响；同一目标连续鼠标事件不会重复启动动画。

绘制支持多个移动目标。重叠标注共享的文字不会重复绘制：当前悬停优先，
其后按活跃目标加入顺序倒序分配重叠区域；各标注的背景和下划线仍独立移动。
因此共享文字不能同时服从两个不同位移。此规则是隔离工具新增的实验行为。
快照文件保持不变，但测试包装已改造为逐标注状态和绘制，不再是原始单目标驱动。

重播、重建布局和关闭悬浮窗会清理所有动画；“退出悬停”按钮只让当前目标退出。
帧记录保存各标注 lifts 和运动终点 goals，配置含进入 duration_ms 与 exit_duration_ms。
同一版本和绘制模式的记录文件会覆盖，比较参数前请自行另存。
